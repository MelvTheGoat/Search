## Cover letter

Eclipse is building an agent-first marketplace that starts with data collection and labelling, and it needs someone to set how that data is labelled and prepared for LLMs. Getting data right before a model sees it is where I have learned the most.

For my compliance retrieval assistant, I designed section-aware chunking that never merges across a document's own structure, so every citation maps to exactly one clause, and I tested it against a fixed-window baseline instead of assuming it was better. I built a 50-question labelled golden set and measured retrieval and generation separately.

For web3-risk-mcp, an MCP server that checks wallets, tokens and contracts across Ethereum, Base, Arbitrum One, Polygon PoS and BNB Chain, I assembled 34 hand-checked addresses as ground truth, with a record and replay harness that reports ROC AUC, precision and recall.

In fraud detection, I dealt with extreme class imbalance and showed how each fix changed calibration, which is the kind of quality metric a labelling pipeline needs.

I have not run RLHF pipelines or fine-tuned an LLM yet. I work in UTC+1 and can start immediately. I would be glad to talk.

## Why this company

Eclipse builds on Ethereum with the Solana VM and is now turning that base into consumer and AI products, starting with data. The role is early and foundational, the team values intellectual honesty, and I already work with on-chain data in my own tools.
