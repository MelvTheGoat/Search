## Cover letter

LangSmith gives teams the observability and evals they need to trust LLM apps, and I have had to build small versions of both for my own projects. Doing it properly for thousands of developers is the job I would like.

For evals, my compliance assistant scores retrieval and generation separately so a failure points to one component, using a labelled 50-question golden set. When one score came out at 0.40, I traced the problem to the offline judge, which is exactly the kind of insight an evals platform should make easy to find.

For the full stack, Reckon has a React review interface over a FastAPI and DuckDB backend, showing match confidence, audit trails and suggested actions. My FPL AI Manager has a FastAPI backend and a React front end, deployed with Docker, and 574 tests. My ledger API runs on PostgreSQL 16 and Redis 7, with idempotency keys on every write and 138 tests.

I have not used Go or TypeScript yet, and I would learn both quickly. I can start immediately and am willing to relocate to San Francisco. I would be glad to talk.
