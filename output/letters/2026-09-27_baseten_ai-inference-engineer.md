## Cover letter

Baseten's forward deployed engineers take a customer's AI idea through evaluation, deployment and monitoring, with clear targets for quality, latency and cost. I have done that full loop on my own projects, and I would like to do it with customers.

For latency, I exported a PyTorch fraud model to ONNX Runtime, 2.9× faster than eager PyTorch at batch size 1, and served it through FastAPI at 5.1 ms p99 against a 50 ms budget. For cost, my compliance assistant runs on GCP Cloud Run within about 225MB of peak memory against a 2GB budget, with request caps in code to bound API spend on a public endpoint. For quality, I evaluate it with a labelled golden set, retrieval and generation scored separately.

I have deployed with Docker on AWS ECS Fargate, GCP Cloud Run and Railway, so I am used to fitting the platform to the job.

The customer-facing part suits me. I teach machine learning to student cohorts, so explaining trade-offs to people with different backgrounds is part of my job. I can start immediately and am willing to relocate to San Francisco. I would be glad to talk.
