## Cover letter

Wallapop is taking its ML Platform to the next level to support personalisation, search, trust and safety, and logistics. I would like to help build that platform, because the MLOps side is the part of my projects I have enjoyed most.

My demand forecasting platform runs as an orchestrated Prefect pipeline with dbt and DuckDB transformations, backtesting, Evidently drift monitoring, conditional retraining and MLflow tracking, with GitHub Actions CI and leakage tests that fail the build.

For real-time inference, I exported a fraud model to ONNX Runtime, 2.9× faster than eager PyTorch, and served it with FastAPI at 5.1 ms p99 against a 50 ms budget. On AWS, I deployed a churn model with Docker on ECS Fargate behind an Application Load Balancer, with CloudWatch logs and CI/CD.

For semantic search, I built hybrid retrieval that fuses BM25 and dense embeddings with reciprocal rank fusion, reaching 0.96 recall@5, and deployed it on GCP Cloud Run.

I have not run Kubernetes, Kafka or SageMaker in production yet, and I would learn them quickly inside a team that already does. I can start immediately and am willing to relocate to Barcelona. I would be glad to talk.
