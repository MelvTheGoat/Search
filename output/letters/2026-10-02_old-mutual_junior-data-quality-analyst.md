## Cover letter

Old Mutual wants a Junior Data Quality Analyst to profile and validate data, reconcile sources, flag duplicates, missing values and anomalies, and keep clear audit evidence. My audit work and my data projects cover these tasks.

As an internal auditor, I analysed financial and operational records to find inconsistencies and irregularities, checking complex transaction data by hand. That taught me to record every finding so someone else can check it.

My reconciliation system matches multi-source transaction feeds to detect duplicate settlements and payout discrepancies, with an audit trail and a review screen for exceptions. My forecasting pipeline runs automated tests that fail the build if any feature reads data from after the forecast origin, so bad data never reaches a model silently, and it monitors drift with Evidently.

I hold a B.Sc. in Statistics, write SQL and Python, and have the Google Data Analytics and Google Advanced Data Analytics certificates. I can start immediately and am willing to relocate to Johannesburg or Cape Town. I would be glad to talk.

Old Mutual's decisions about customers depend on data being complete and correct, and this team owns that. A role built around checking and fixing data suits my audit background.
