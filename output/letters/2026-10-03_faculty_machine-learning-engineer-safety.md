## Cover letter

Faculty's National Security and AI Safety team wants a Machine Learning Engineer to build production ML systems and tools for testing frontier AI models, including LLM applications, agent harnesses and safety evaluations. Evaluation is the thread through my AI projects.

In my compliance assistant, I built an evaluation harness that scores retrieval and generation separately and enforces a refusal rule across the prompt, the output guardrail and the harness. When the offline stub judge gave a 0.40 refusal-correctness result, I traced it to a lexical-overlap limit in the judge itself rather than reporting it as system behaviour, and named re-validation against a live provider as the next step.

My web3-risk-mcp server gives AI assistants six read-only tools and refuses any call outside a read-only allow-list, and I measured it with a record and replay harness on 34 hand-checked addresses. I deploy with Docker on GCP Cloud Run and AWS ECS Fargate, with CI on GitHub Actions, and my fraud model serves at 5.1 ms p99 through ONNX Runtime.

I have not used Kubernetes. I hold a B.Sc. in Statistics, can start immediately and am willing to relocate to London. I would be glad to talk.
