## Cover letter

Block is looking for an early-career data scientist to work on payments across Square and Cash App, from success rate to cost to risk. Payments data is where most of my projects live.

I built Reckon, a payment reconciliation system that takes processor webhooks and bank settlement files, joins them with temporal logic and tolerance thresholds in DuckDB, and flags uncollected revenue, duplicate settlements and payout discrepancies. I built a fraud detection system judged under an explicit cost model, where sequence models cut expected cost per transaction by 27%. I also built a double-entry ledger API with PostgreSQL and Redis, so I understand how money should move through a system, not only how to analyse it afterwards.

The role asks for ETL pipelines, experiments and cloud infrastructure. My forecasting platform runs on Prefect, dbt and DuckDB with MLflow tracking and CI on GitHub Actions, and my uplift study includes a power and MDE calculator for experiment design. On the AI side, I built an MCP server that gives AI assistants real tools.

I hold a B.Sc. in Statistics. I can start immediately and would relocate to the Bay Area. I would like to talk about the role.
