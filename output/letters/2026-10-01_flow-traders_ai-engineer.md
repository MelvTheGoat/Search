## Cover letter

Flow Traders wants an AI Engineer to turn real workflows from Trading, Risk, Compliance and Operations into agents, with approval gates, audit trails, evaluation and safeguards against hallucinations. My AI projects were built around those same controls.

I built web3-risk-mcp, an MCP server that gives AI assistants six read-only tools to check a wallet, token or contract for risk. It returns a 0 to 100 score with a reason for every point, uses caching, rate limits and retries per source so one failing source never breaks an investigation, and refuses any call outside a read-only allow-list. I evaluated it on 34 hand-checked addresses with a record and replay harness.

My compliance assistant combines BM25 and dense retrieval through reciprocal rank fusion and reached 0.96 recall@5 on a 50-question golden set. It refuses when unsure and strips any citation the model gave but never retrieved. For reconciliation, my payment system pairs matching rules with a human-in-the-loop review screen showing confidence scores and audit trails.

I deploy with Docker, FastAPI and GitHub Actions on GCP Cloud Run and AWS. I hold a B.Sc. in Statistics, can start immediately and am willing to relocate to Amsterdam. I would be glad to talk.
