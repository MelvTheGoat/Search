## Cover letter

ClaimSorted wants a Product Engineer to build AI agents that do real work on real insurance claims, and to own the risk of what happens when an automation is wrong. That last point is how I build systems.

My payment reconciliation system, Reckon, is deployed and processes multi-source transaction feeds to find duplicate settlements and payout discrepancies. It combines deterministic matching rules with ML-assisted resolution, and sends exceptions to a React review screen that shows match confidence, audit trails and suggested actions, so a person stays in charge of the hard cases.

My compliance assistant is designed to fail safely. It refuses rather than guesses, and it strips any citation the model gave but never retrieved. My web3-risk-mcp server gives AI assistants six read-only tools and refuses any call outside a read-only allow-list, because an agent should only take the actions it is meant to take.

I build end to end with Python, FastAPI, React and Docker, and I have deployed on GCP Cloud Run and Railway. I can start immediately and am willing to relocate to London. I would be glad to talk.
