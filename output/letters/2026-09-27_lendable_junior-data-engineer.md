## Cover letter

Lendable's Data Platform sits at the centre of the business and aims to move teams from idea to insight quickly without losing reliability, cost control or security. I like that balance, and it is the one I have had to strike in my own pipelines.

My demand forecasting platform is an orchestrated Prefect pipeline with dbt and DuckDB transformations, backtesting, drift monitoring and conditional retraining. I wrote automated leakage tests that fail the build if any feature reads past the forecast origin, because a pipeline should catch its own mistakes.

For Reckon, my payment reconciliation system, I built a multi-stage pipeline with DuckDB and FastAPI that joins asynchronous processor webhooks with bank settlement files using temporal joins and tolerance thresholds, then deployed it in Docker with structured logs and integration tests.

My double-entry ledger API on PostgreSQL 16 and Redis 7 enforces its rules in the database and has 138 tests against real services. I have also deployed a model on AWS ECS Fargate with GitHub Actions CI/CD.

I have not used Snowflake or Terraform yet, but dbt, SQL and cloud deployment carry over, and I pick up tools quickly. I can start immediately and am willing to relocate to London. I would be glad to talk.
