## Cover letter

ServiceNow's Advanced Technology Group wants AI and ML solutions that any user can run, whatever their technical knowledge. I build models and make them easy for people to use and trust.

My fraud detection system compares a GRU, a temporal convolutional network and a causally masked Transformer over customer transaction histories, each under 115k parameters and trainable on a CPU in under 6 minutes. I exported the served model to ONNX Runtime, which ran 2.9× faster than eager PyTorch at batch size 1, and served it with FastAPI at 5.1 ms p99 against a 50 ms budget.

On the language side, I built and deployed a retrieval assistant with hybrid search, a refusal guardrail and citation checks, and scored retrieval and generation separately on a 50-question golden set. I also built an MCP server that gives AI assistants tools to check crypto wallets and contracts, with a reason for every point of its score. That is the idea of putting AI inside the tools people already use.

I write modular, tested Python with CI on GitHub Actions, and I teach machine learning to student cohorts. I can start immediately, am willing to relocate to Hyderabad and would be glad to talk.
