## Cover letter

Mercuryo wants someone who can turn a request from Finance, Legal, Operations or Support into a working tool in days, using LLMs, APIs and MCP connectors. Building tools like that end to end is what my recent projects are.

I built web3-risk-mcp, an MCP server that gives AI assistants such as Claude Desktop and Cursor six read-only tools to check a crypto wallet, token or smart contract before anyone interacts with it. It returns a 0 to 100 risk score with a reason for every point. Its HTTP layer has caching, per-source rate limits and retries, so one failing source never breaks an investigation.

For document work, I built and deployed a retrieval assistant over regulatory documents with hybrid search, a refusal guardrail when the answer is not supported, and a check that removes any citation the model never retrieved. I measured it on a 50-question golden set and reached 0.96 recall@5. It runs on GCP Cloud Run with request caps to bound API cost.

I also built a payment reconciliation service with a review screen for exceptions, so I am used to handing tools to people who are not engineers. I work in UTC+1, can start immediately and would be glad to talk.
