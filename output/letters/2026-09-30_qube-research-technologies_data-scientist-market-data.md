## Cover letter

QRT's market data team builds and owns the Python pipelines that extract, clean, validate and deliver pricing and reference datasets to researchers and traders. Building reliable data pipelines is the core of my recent work.

My forecasting platform runs as an orchestrated Prefect pipeline covering ingestion, dbt and DuckDB transformations, backtesting, drift monitoring and conditional retraining. Automated tests fail the build if any feature reads data from after the forecast origin, so bad data never reaches a model silently.

I also built a reconciliation pipeline with DuckDB and FastAPI that matches multi-source transaction feeds with temporal join logic and tolerance thresholds, to handle records that arrive late or out of order. That is the same problem as aligning prices from several sources.

For market data, my web3-risk-mcp tool reads live data from DEX and chain sources, with caching, per-source rate limits and retries, so one failing source never breaks the output and missing data lowers confidence instead of the result. I hold a B.Sc. in Statistics, write Python and SQL daily, can start immediately and am willing to relocate to Hong Kong. I would be glad to talk.
