## Cover letter

Old Mutual wants a junior data engineer to build and support pipelines, ETL processes and datasets, with guidance from experienced engineers, while following strict standards for testing, source control and governance. That mix of delivery and discipline is how I have built my own pipelines.

My demand forecasting platform is an orchestrated Prefect pipeline with dbt and DuckDB transformations, backtesting, drift monitoring and conditional retraining. I wrote automated leakage tests that fail the build if any feature reads past the forecast origin, because a pipeline should catch bad data before anyone uses it.

For Reckon, my payment reconciliation system, I built a multi-stage pipeline with DuckDB and FastAPI that joins processor webhooks with bank settlement files using temporal joins and tolerance thresholds, then deployed it in Docker with structured logs, integration tests and persistent state tracking. My double-entry ledger API on PostgreSQL has 138 tests against real services, and all my work goes through Git and GitHub Actions.

I have not worked in a formal release train yet, and I would welcome the structure. I hold a B.Sc. in Statistics, can start immediately and am willing to relocate to Cape Town. I would be glad to talk.
