## Cover letter

The Discover AI team wants early-career engineers who can build Python services with FastAPI and help ship RAG, semantic search and vector search. That is close to what I have been building on my own.

My fintech compliance RAG assistant answers regulatory questions with hybrid retrieval: BM25 and dense MiniLM embeddings served with ONNX, fused with reciprocal rank fusion. It reached 0.96 recall@5 and 0.842 MRR on a 50-question labelled golden set. I added section-aware chunking so every citation maps to one clause, a refusal path for uncertain answers, and a check that strips citations the model never retrieved. It runs on FastAPI and Docker on GCP Cloud Run.

I also built an MCP server that gives AI assistants six read-only tools, with caching, rate limits and retries, and a double-entry ledger API with idempotency keys and 138 tests. My projects run CI on GitHub Actions, and I write tests before I call something done.

I have not used Azure or LangChain yet, but the ideas behind them are ones I already work with. I can start immediately and would relocate to Pune. I would like to talk about the role.
