## Cover letter

DataLens Africa builds clean datasets for training AI, and wants a data engineer to design pipelines for collecting, cleaning and transforming data, automate dataset validation, and prepare data with AI engineers for model training. Reliable data pipelines are the core of my recent work.

My forecasting platform runs as an orchestrated Prefect pipeline covering ingestion, dbt and DuckDB transformations, backtesting and drift monitoring. Automated tests fail the build if any feature reads past the forecast origin, so bad data never reaches a model silently.

For dataset quality, my compliance assistant was evaluated against a 50-question labelled golden set, and my web3-risk-mcp project has an evaluation set of 34 hand-checked addresses with a record and replay harness. My reconciliation pipeline matches multi-source feeds with DuckDB and FastAPI and sends exceptions to a human review screen, the same pattern as an annotation QA queue.

I hold a B.Sc. in Statistics, write Python and SQL with Pandas and NumPy, and have deployed on GCP and AWS. I can start immediately and would be glad to talk.

## Why this company

DataLens Africa works on the data that AI models learn from, and good datasets decide how well those models work. Building the pipelines and checks behind clean data is work I enjoy.
