## Cover letter

micro1 wants an AI/ML engineer to improve its AI recruiting agent: designing prompts, RAG and agent workflows, evaluating model performance and shipping features to production. Building and measuring LLM systems is what my projects are about.

My compliance assistant combines BM25 and dense retrieval through reciprocal rank fusion and reached 0.96 recall@5 and 0.842 MRR on a 50-question labelled golden set. I scored retrieval and generation separately, so a drop in quality can be traced to one part, and I deployed it as a FastAPI and Docker service on GCP Cloud Run.

My web3-risk-mcp server gives AI assistants six tools for checking risk, with caching, rate limits and retries with backoff, so one failing source never breaks an answer. For production engineering in general, my FPL AI Manager runs scheduled jobs against a live API with 574 tests and one-command deployment.

I have not used LangChain or LangGraph, and I would pick them up quickly. I hold a B.Sc. in Statistics, can start immediately and work in UTC+1. I would be glad to talk.
