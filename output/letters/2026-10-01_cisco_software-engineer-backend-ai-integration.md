## Cover letter

Cisco's CX Engineering team wants a backend engineer to build low-latency Python APIs and bring RAG, vector search and agentic workflows into enterprise products. My backend and retrieval projects cover both halves.

I built a double-entry ledger and payments API with FastAPI, PostgreSQL, Redis and Alembic migrations, where every mutating endpoint needs an Idempotency-Key and events go out through a transactional outbox. Load tests showed throughput saturating at about 250 to 260 req/s, and removing the hot account cut transfer p99 from 1800 ms to 390 ms. It has 138 tests against real PostgreSQL and real Redis.

On the AI side, my compliance assistant combines BM25 and dense retrieval through reciprocal rank fusion and reached 0.96 recall@5 on a 50-question golden set, with guardrails that make it refuse rather than guess. I also built an MCP server that gives AI assistants six read-only tools, with caching, per-source rate limits and retries.

I deploy with Docker and GitHub Actions to GCP Cloud Run and AWS ECS Fargate. The post asks for more experience than I have, so I am applying on the strength of this work. I hold a B.Sc. in Statistics, can start immediately and am willing to relocate to Bangalore. I would be glad to talk.
