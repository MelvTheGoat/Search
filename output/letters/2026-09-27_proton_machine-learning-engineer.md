## Cover letter

Proton's MSA team combines machine learning and human judgement to make real-time decisions on spam, abuse and account security. Most of my recent projects are fraud and abuse detection systems, and this team is where that work would matter most.

My sequence-based fraud detection system compares a GRU, a temporal convolutional network and a causally masked Transformer over customer transaction histories. I studied results by attack type, including account takeover, and handled extreme class imbalance while keeping probabilities calibrated, bringing ECE down to 0.0005. The model runs in real time through ONNX Runtime at 5.1 ms p99, with attention-based attribution showing which past transactions drove each flag.

For agentic AI, I built web3-risk-mcp, an MCP server that gives AI assistants tools to investigate wallets and contracts. It uses an explainable rule-based score where decisive findings can never be hidden by trust signals, and one failing data source never breaks an investigation.

My forecasting platform shows the MLOps side: drift monitoring and conditional retraining inside a scheduled pipeline.

I can start immediately and would relocate to Geneva or Taipei. I would be glad to talk.

## Why this company

Proton treats privacy as a right, which makes abuse detection harder, because the system cannot simply read everything. That constraint makes the ML problems more interesting. The team also works across account security and agentic AI, the two areas I am building in now.
