## Cover letter

Cambium's CAI team turns research models into fast, reliable scoring systems, with a focus on converting PyTorch models to ONNX and deploying on AWS ECS. That is almost exactly the path my fraud detection project took.

I built sequence models in PyTorch, a GRU, a temporal convolutional network and a causally masked Transformer, then exported the chosen model to ONNX Runtime, which ran 2.9× faster than eager PyTorch at batch size 1. Served through FastAPI, it reached 5.1 ms p99 end to end against a 50 ms budget, with per-decision audit logging.

On AWS, I deployed a churn model as a FastAPI service in Docker on ECS Fargate behind an Application Load Balancer, with CloudWatch logs and GitHub Actions CI/CD. My compliance assistant runs on GCP Cloud Run within about 225MB of memory, so I am used to watching cost and footprint.

Working with statisticians and researchers would feel natural: I hold a B.Sc. in Statistics, teach machine learning at SQI College of ICT and write tested code with pytest. I have not used Lambda or Flash Attention yet.

I work in UTC+1 and can start immediately. I would be glad to talk.

Oluwatobi Melvyn Mayungbo
mlvyn.t@gmail.com

## Why this company

Cambium builds learning and assessment tools, and its scoring models have to run fast and reliably for its clients. The team mixes psychometricians, statisticians and engineers, which suits someone with a statistics degree who builds production systems.
