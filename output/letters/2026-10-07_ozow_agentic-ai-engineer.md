## Cover letter

Ozow is building AI agents that automate real work across operations, support, fraud and risk, and wants an engineer who writes evaluation tests before release and can explain how each agent fails. I build AI systems that way.

My compliance assistant answers regulatory questions with hybrid retrieval and reached 0.96 recall@5 on a 50-question labelled golden set. It refuses rather than guesses, using a rule enforced across the prompt, the output guardrail and the evaluation harness, and it strips any citation the model gave but never retrieved. I scored retrieval and generation separately, so every failure points to one component.

My web3-risk-mcp server gives AI assistants six read-only tools and refuses any call outside a read-only allow-list, the same idea as well-scoped integrations to internal APIs. I also know the payments side: my fraud detection and reconciliation systems were built around transaction data, with a review screen where a person signs off on the hard cases.

I work in Python with FastAPI, Docker and Git, and I have not used C# or .NET. I hold a B.Sc. in Statistics, can start immediately and am willing to relocate to Cape Town. I would be glad to talk.
