## Cover letter

Bosch's mobility team wants a Junior Data Scientist to build data pipelines and machine learning models for cloud services, telemetry analytics and event detection, and to own them from prototype to monitoring. That full cycle is how I build my projects.

My demand forecasting platform runs as an orchestrated Prefect pipeline covering ingestion, dbt and DuckDB transformations, backtesting, drift monitoring and conditional retraining. I validated it with rolling-origin backtesting across 6 folds, and automated leakage tests fail the build if any feature reads past the forecast origin. Shipping the cost-optimal quantile cut expected cost by 25% on the same model.

For event detection, my fraud system models sequences of customer transactions with GRU, TCN and Transformer models, compares them with a LightGBM baseline, and serves the model through ONNX Runtime at 5.1 ms p99. My reconciliation pipeline matches multi-source feeds that arrive late or out of order, the same problem that streams of sensor data have.

I hold a B.Sc. in Statistics, write Python and SQL, use Git and GitHub Actions, and can start immediately. I am willing to relocate to Cluj-Napoca. I would be glad to talk.
