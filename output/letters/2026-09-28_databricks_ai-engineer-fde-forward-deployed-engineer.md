## Cover letter

Databricks' AI FDE team helps customers take first-of-their-kind GenAI applications into production, including their evaluation, and explains the work to technical and non-technical people. I build, evaluate and deploy GenAI applications, and I teach.

I built and deployed a retrieval assistant over regulatory documents that combines BM25 and dense embeddings with reciprocal rank fusion. I wrote the evaluation first: a 50-question golden set with retrieval and generation scored separately, reaching 0.96 recall@5 and 0.842 MRR. Generation refuses when the sources do not support an answer, and a check removes any citation the model never retrieved. It runs on GCP Cloud Run with request caps to keep API cost bounded.

I also built an MCP server that gives AI assistants six tools to check crypto risk, and deployed a churn model on AWS ECS Fargate with CloudWatch logs and CI/CD. Working across GCP and AWS is familiar to me.

I teach machine learning to student cohorts, so explaining technical ideas to mixed audiences is part of my week. I hold a B.Sc. in Statistics rather than a graduate degree. I can start immediately, am open to remote work or relocating within India, and would be glad to talk.

Databricks sits under the data and AI stack of thousands of companies, so a GenAI application shipped with a customer there reaches real users quickly. The FDE role mixes building, deploying and teaching, which is the mix I want.
